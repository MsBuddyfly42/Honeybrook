# Nell’s community-life photographs and props

Generated with the built-in image-generation tool for this project. WebP conversions preserve prop transparency. No original imagery is replaced.

- `apiary.webp`: photographic woodland beekeeping yard; timber hives, flowers and a workbench, no humans or bears. Used only for apiary scenes.
- `home-props.webp`: transparent four-column, two-row photographic object atlas: kettle, cup, bread basket, honey jar; cloth, copper pot, brush, notebook.
- `bee-props.webp`: transparent four-column, two-row photographic object atlas: gloves, unlit smoker, capped frame, hive tool; empty jar, filled honey jar, entrance reducer, potted clover.
- `../nell/welcome.webp`: photographic first-person welcome outside timber-and-stone Welcome House. Sammy wears an uneven blue-patched coat beside an adult apron-wearing bear. No present-day humans appear in the background. Final edit specifically replaces the generated stone bridge with a simple wooden plank footbridge, preserving the bears and the rest of the scene.

The prompts requested warm, colorful photographic bear-country textures, realistic fur/materials, no cartoon style, no writing and no watermark. Each atlas prompt specified its object order, separate objects and a transparent background. These are game-adaptation assets rather than evidence of additional manuscript facts. Exact dimensions and hashes are in `manifest.json`.
