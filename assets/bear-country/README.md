# Bear Hollow scenery and fonts

Six original generated scenery sheets made for Honeybrook on October 23, 2026, using the established Bear Hollow geography and Honeybrook completed-work photography as references. Each sheet holds four separate 768×512 photographic-style scene views, served as one WebP for efficient reuse. They are authored fictional setting images, not photographs of real bear families or buildings.

- cottages-a: Cedar Hearth exterior/interior; Willowbank exterior/interior.
- cottages-b: Clover Patch exterior/interior; Maple Lantern exterior/interior.
- cottages-c: Fernwood exterior/interior; Bluebell Nook exterior/interior.
- workplaces-a: honey house; porridge kitchen; covered kindling/timber shed; brook footbridge.
- workplaces-b: kitchen garden; fountain/flowers; bakery; family gathering pavilion.
- hollow-places: Hollow overview; Cottage Lane; founding cottage; completed family porridge meal.

Original generated PNGs are retained in the execution workspace, outside the repository. WebP conversion changes format/quality only. Game instructions and strict saved work counts determine the quantities and outcomes; scenery is a setting, not an inventory counter.

Locally hosted variable fonts: Fraunces (headings, Honeybrook Hearth alias) and Nunito (body, Honeybrook Rounded alias), from https://github.com/google/fonts/tree/main/ofl/fraunces and https://github.com/google/fonts/tree/main/ofl/nunito . Their SIL Open Font License files are included in `fonts/`. The Hollow does not require a font-service request for these fonts. Original typeface names are unchanged inside the font files.
