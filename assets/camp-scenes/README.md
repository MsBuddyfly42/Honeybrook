# Camp photographs

Four generated photographic-style sheets add sixteen views without replacing any existing Honeybrook image. Each sheet is 1536×1024, arranged as four 768×512 views (top left, top right, bottom left, bottom right). The renderer reserves a 3:2 viewport and crops the appropriate tile.

- `shelter-01.webp`: whole-roster check-in; comfort rooms; underground dining; sanitation.
- `shelter-02.webp`: underground recreation; KJV study; emergency supplies; commercial kitchen.
- `housing.webp`: family cabins; cub bunkhouse; adult staff quarters; tents/yurts.
- `infrastructure.webp`: chapel; pantry; maintenance/equipment; prepared firewood storage.

All four sheets were visually inspected for the approved bear-country photographic style, suitable rooms and naturally positioned bears. These are authored game extensions, not new manuscript illustrations or historical claims. `manifest.json` records dimensions and SHA-256 hashes; `camp-data.json` and the activity catalog bind rooms to tiles. No paid image service, remote image dependency or new recurring hosting charge is needed.
