# Welcome House — a woodland boarding house

The owner's final design is a huge timber-and-stone cottage boarding house: visitors arrive **outside**, then choose to enter a domestic front hall with a receptionist's writing desk. The shared sleeping space is **one big wide cozy bedroom**, with twenty bunk areas, forty shared beds, quilts, curtains, rugs and a central sitting nook. Ten private family bedrooms keep households together. There are 24 connected rooms, each with ten local assignments.

The shared bathroom quarter contains six private toilet cubicles and six handwashing sinks. A separate private accessible family washroom provides supported-access space and a changing table. Bunk selectors describe twenty areas; no occupancy or completed booking/check-in is invented.
